# delete-word-01

The one word I'd erase from the dictionary forever: **irregardless**. It is a double negative pretending to be a word while "regardless" already does the entire job — deleting it costs the language nothing and saves everyone from hearing it ever again.

`main.ts` writes the entry to `/output/entry.txt` for the make.fun bounty [The Word You'd Delete From the Dictionary](https://make.fun/bounty/u-puan-the-word-you-d-delete-from-the-dictionary-9e774bc2).
